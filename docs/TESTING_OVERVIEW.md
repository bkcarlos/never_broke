### 场景2: 多设备并发操作 🔄
```
Device 1 (手机)  →  3笔支出 × 100元  =  -300元
```

**验证点**:
- ✅ 9笔交易全部成功
- ✅ 最终余额精确

## 🛠️ 一键使用

### 最简单的方式（使用 Mage 推荐）

```bash
cd backend-go

# Step 1: 设置测试环境（仅首次）
mage test:setupDB

# Step 2: 运行所有测试
mage test:all

# Step 3: 查看覆盖率
mage test:coverage
```

### 或使用 Makefile

```bash
cd backend-go

# Step 1: 设置测试环境（仅首次）
make setup-test-db

# Step 2: 运行所有测试
make test-all

# Step 3: 查看覆盖率
make test-coverage
```

### 体验复杂场景

```bash
cd backend-go

# 使用 Mage
mage test:concurrent    # 多用户并发测试
mage test:stress        # 压力测试
mage test:demo          # 演示所有场景

# 或使用脚本
cd tests/integration
./demo_test_scenarios.sh
./run_tests.sh -v -t TestMultiUser          # 多用户测试
./run_tests.sh -v -t TestRealWorldScenario  # 真实场景
```

```go
var wg sync.WaitGroup
results := make(chan bool, 10)

    wg.Add(1)
    go func() {
        defer wg.Done()
        success := doSomething()
        results <- success
    }()
}

wg.Wait()
close(results)

// 验证所有结果
```
